# Manage local HTTP lifecycle behind one seam

The Local Web UI and standalone OBS Overlay use one managed HTTP lifecycle Module rather than manually wiring connection state in each Adapter. The Module owns transactional thread start, absolute request-read deadlines, request generations, operation promotion, socket interruption, listener shutdown, handler drain, bounded stream participants, and cleanup-error aggregation. Local Web UI shutdown reliably drains accepted operations so writes are not truncated; standalone Overlay shutdown cancels accepted reads. SSE remains tracked as an accepted ordinary operation while its EventStreams participant supplies mailbox wakeup and socket cancellation, avoiding an unowned handoff window. Short socket polls are an internal Windows interrupt mechanism and do not replace the absolute deadline.
